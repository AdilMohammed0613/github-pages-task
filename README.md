# GitHub Pages Static Website

## DevOps Internship - Task 6

This project demonstrates how to host a static website using GitHub Pages.

## Technologies Used

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Project Features

- Simple responsive static website
- HTML structure
- Custom CSS styling
- Hosted using GitHub Pages

## Deployment

The website was created using an `index.html` file and pushed to GitHub.

GitHub Pages was enabled using:

- Branch: `main`
- Folder: `/ (root)`
